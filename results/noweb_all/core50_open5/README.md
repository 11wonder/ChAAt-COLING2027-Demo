# Option-Free Probe Status

Thirty model responses were collected for five option-free generation tasks.
Keyword scores in `open_details.csv` are screening signals only and contain
known false positives and false negatives.

Independent human scoring is required before these results can enter the
paper. The blinded form is `docs/robustness_open5_blind_form.csv`; the model
mapping is `blind_map.csv`. Do not give the mapping to the rater.
